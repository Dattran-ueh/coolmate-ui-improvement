# Lab07 — CSS nâng cao

## Sinh viên
- Họ và tên: Trần Gia Đạt
- MSSV: 31241024727
- Môn học: Phát triển ứng dụng TMĐT

## Mục tiêu
Thực hành luồng hiển thị, positioning, z-index, float, clear,
bố cục nhiều cột, responsive, transform, transition, filter,
animation và Bootstrap.

## Cấu trúc
- index.html: trang giới thiệu và liên kết 19 Exercise;
  ảnh đại diện được nhúng trực tiếp trong HTML.
- Lab07/: các file HTML/CSS bài thực hành.
- Lab07/images/: hình ảnh bài tập.
- Lab07/bootstrap/: thư viện Bootstrap và phông biểu tượng.

## Nội dung
- Bài 01–04: luồng hiển thị và định vị.
- Bài 05–09: float, clear và đặt nội dung lên ảnh.
- Bài 10–11: bố cục hai cột và ba cột.
- Bài 12–13: media queries, viewport và menu responsive.
- Bài 14–18: transform, transition, filter và animation.
- Bài 19: hệ thống lưới và thành phần Bootstrap.

Bài 13 tiếp tục trên các file bài 12 theo hướng dẫn Lab07.
Hai liên kết trong trang tổng hợp mở chung phiên bản hoàn thiện.

## Cách chạy
Mở index.html bằng trình duyệt rồi chọn bài cần xem.
Giữ nguyên cấu trúc thư mục để các đường dẫn hoạt động.

Bài 15–17 có tương tác hover. Bài 18 tự chạy khi tải trang.
Các nút View và Cart trong bài 19 minh họa giao diện Bootstrap,
chưa triển khai chức năng nghiệp vụ.

## Kiểm tra
- Desktop: 1200 × 900 px.
- Mobile: 390 × 844 px.
- Bài 12–13: kiểm tra thêm chiều rộng 480 px và 481 px.
